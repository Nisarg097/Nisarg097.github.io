03 PowerShell Onboarding — Add & Remove Devices in AD and SCCM A PowerShell script connected to the AD server and SCCM, so devices can be added or removed from both systems in one place. AutomationPowerShellActive DirectorySCCMCodex · Claude Code +

Overview

I built a PowerShell script that connects to the Active Directory server and to SCCM, so I can easily add or remove devices from both systems through the script instead of doing the same work manually in each console. I use Codex and Claude Code as part of this workflow — to develop and refine the scripts, find and fix scripting errors, and optimize the automation.

Problem

Onboarding and removing devices meant repeating the same steps separately in Active Directory and in SCCM. Doing it by hand in two places is slow, repetitive manual work, and easy to leave half-done in one system.

My Role

Designed and wrote the script, and use it as part of the device onboarding and removal workflow. I also use AI-assisted scripting tools for related IT administration work — automating user administration tasks and running system diagnostics from the command line.

Tech Used

PowerShellActive DirectorySCCMCodexClaude Code

Process

Connect the script to the AD server and to SCCM, then run the add or remove action for a device once and have it applied in both systems, keeping the two records in step. Use Codex and Claude Code to debug errors, test changes, and streamline the workflow before running it against live systems.

Solution

One scripted action for device onboarding and removal across AD and SCCM, replacing the repeated manual steps in both consoles and saving manual work on every device.

AD + SCCM in one scriptAdd & remove devicesManual work saved
Lessons LearnedWhen the same device has to exist in two systems, the fix is to update both from one place. A small script beats a careful manual routine, because the routine eventually gets skipped.
